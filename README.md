# ET-OptMETEST

This repository contains scripts, metabolic models, and results for testing ET-OptME with *Corynebacterium glutamicum*.

## Original Work

This project is based on [ET-OptME](https://github.com/Jingyi-Cai/ET-OptME). Please refer to and cite the original publication:

**Improving metabolic engineering design with enzyme-thermo optimization.**  
*Metabolic Engineering*.  
https://doi.org/10.1016/j.ymben.2025.05.009

## Installation

```bash
git clone https://github.com/zhangxinyuya/ET-OptMETEST.git
cd ET-OptMETEST
pip install -r requirements.txt
```

A compatible optimization solver, such as Gurobi or CPLEX, is required.
